    הגדרות סיכום אוטומטי (חינם)

    כדי שהכפתור "סכם את הפגישה" יסכם כאן ישירות, צריך מפתח חינמי של Google Gemini. הוא לא דורש כרטיס אשראי:

    1. היכנסו ל-aistudio.google.com/apikey עם חשבון הגוגל שלכם.
    2. לחצו Create API key והעתיקו את המפתח.
    3. הדביקו אותו כאן ולחצו "שמור מפתח".

    המפתח נשמר רק בדפדפן הזה. בחשבון החינמי גוגל רשאית להשתמש בתוכן לשיפור המוצרים שלה, אז לפגישות רגישות עדיף "העתק ל-Claude".
